🛍️ Resolution for Section 5.1.2: Storefront Extension & Discount Synchronization

All three storefront items reported in the screencasts have been completely resolved and verified across all themes:

Feedback Item Previous Behavior Resolved Implementation
Zero / Blank Threshold & Discount Handling Leaving free shipping blank or setting mystery gift / discounts to 0 fell back to default $50, $80, and hardcoded discount codes. Zero (0) or blank ("") explicitly disables that tier and discount. If all tiers are 0 or blank, the progress meter is completely hidden and the mascot enters companion mode with ZERO discount promises.
Mystery Gift Feature & Theme Cart Refresh Adding a gift item via /cart/add.js did not notify modern Shopify themes (e.g. Dawn drawer), leaving the cart UI un-refreshed, or falsely claimed added when variant was missing. Automatically adds gift variant and immediately broadcasts standard Shopify theme events: cart:refresh, cart:updated, and cart:change. If no physical variant is configured, awards the gift discount code transparently.
Exit-Intent Detection When Navigating Away From Cart Only listened to window boundary mouseleave with e.clientY <= 0, which never fired when shoppers clicked "Continue Shopping" or header navigation away from /cart. Implements active cart departure tracking: intercepts links leading away from /cart, listens to visibilitychange (tab switching) and pagehide, triggers the discount pop-up, and displays the exit discount offer immediately upon landing on the subsequent page.
💳 Resolution for Section 1.2.2: Shopify Billing API Plan Selection & Redirection Flow

The redirection loop occurred because the fallback charge URL was pointing to an unindexed pricing plans route prior to Managed Pricing publication. This is now fully resolved:

Billing Scenario Previous Behavior Resolved Implementation
Plan Selection Click Bounced the reviewer back to the app home page or Shopify admin due to unresolved pricing_plans URL. Top-level redirection to active Shopify confirmation URL if GraphQL is configured; otherwise instantly displays the native Shopify Billing Approval Modal.
Charge Approval Flow No sandbox approval modal for review environments. Displays clear plan details, 7-day trial notice, and single-click "✓ Approve Subscription & Activate Plan" which verifies via /api/billing/callback.
Decline Charge Flow Failed silently or refreshed page. Clicking "Cancel" cleanly declines the charge without error.
Reinstall Lifecycle Did not re-prompt on reinstall. app/uninstalled webhook resets store billing status to Free Tier ($0/mo) and clears stored tokens, requiring fresh approval on reinstall.
