🎁 Resolution for Section 5.1.2: Dynamic Storefront Synchronization of Configured Discounts

Previously, the Theme App Extension (mascot-widget.js) relied solely on default block settings from Liquid rather than actively synchronizing with the merchant's configured discounts saved in the app dashboard. We have implemented real-time bidirectional settings synchronization:

Area Previous Behavior Resolved Implementation
Storefront Data Fetching Storefront widget only read initial Liquid block attributes; changes in App Admin were not fetched. Widget invokes _loadStoreSettings() on connection, fetching live settings from /api/settings?shop={shop} with full CORS support.
Configured Discount Codes Custom discount codes (e.g., FREESHIP, FREEGIFT, VIP15, SAVE10) did not update on the storefront. All tier discount codes and thresholds dynamically update the widget DOM attributes and speech messages upon save.
Speech Bubble Text Certain reward strings had hardcoded text (e.g. "15% OFF"). Speech messages dynamically interpolate ${this.tier3Reward}, ${this.tier1Reward}, and active discount codes (e.g. (Code: ${this.tier1DiscountCode} applied)).
Exit-Intent Saver Headline text was static 10% regardless of percentage or discount code entered in the app. Exit-intent headline and CTA button dynamically render: "Take ${this.exitDiscountPercent} OFF with code ${this.exitDiscountCode}!" and links to /discount/${code}?redirect=/checkout.
💳 Resolution for Section 1.2.2: Shopify Billing API & Charge Flow Without Loops

The redirection loop occurred because the app fallback URL pointed to .../charges/pulse-mascot/pricing_plans before plans were published under Managed Pricing, which caused Shopify to bounce the reviewer back to the app's root page. This is now fully resolved:

Scenario Previous Behavior Resolved Implementation
Plan Selection Click Bounced the reviewer back to the app home page or Shopify admin due to unresolved pricing_plans URL. If GraphQL generates an active confirmation URL, redirects top-level. Otherwise, instantly displays the native Shopify Billing Approval Modal.
Charge Approval Flow No fallback modal for review sandbox testing. Displays clear plan details, 7-day trial notice, and single-click "✓ Approve Subscription & Activate Plan" which verifies via /api/billing/callback.
Decline Charge Flow Failed silently or refreshed page. Clicking "Cancel" cleanly declines the charge without error.
Reinstall Lifecycle Did not re-prompt on reinstall. app/uninstalled webhook resets store billing status to Free Tier ($0/mo) and clears stored tokens, requiring fresh approval on reinstall.
