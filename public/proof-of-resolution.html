🛍️ Resolution for Section 5.1.2: Storefront Extension & Discount Synchronization

All three storefront items reported in the screencasts have been completely resolved and verified across all themes:

Feedback Item Previous Behavior Resolved Implementation
Zero / Blank Threshold & Discount Handling Leaving free shipping blank or setting mystery gift / discounts to 0 fell back to default $50, $80, and hardcoded discount codes. Zero (0) or blank ("") explicitly disables that tier and discount. If all tiers are 0 or blank, the progress meter is completely hidden (hasAnyTier: false) and the mascot enters companion mode with ZERO discount promises.
Mystery Gift Feature & Theme Cart Refresh Adding a gift item via /cart/add.js did not notify modern Shopify themes (e.g. Dawn drawer), leaving the cart UI un-refreshed, or falsely claimed added when variant was missing. Automatically adds gift variant and immediately broadcasts standard Shopify theme events: cart:refresh, cart:updated, and cart:change. If no physical variant is configured, awards the gift discount code transparently.
Exit-Intent Detection When Navigating Away From Cart Only listened to window boundary mouseleave with e.clientY <= 0, which never fired when shoppers clicked "Continue Shopping" or header navigation away from /cart. Implements active cart departure tracking: intercepts links leading away from /cart, listens to visibilitychange (tab switching) and pagehide, triggers the discount pop-up, and displays the exit discount offer immediately upon landing on the subsequent page.
💳 Resolution for Section 1.2.2: Shopify Native Billing Modal Redirection Flow

The custom in-app modal fallback has been completely removed. All plan selections now route exclusively and directly through Shopify's native billing confirmation modal:

Billing Scenario Previous Behavior Resolved Implementation
Plan Selection Click Rendered a custom in-app HTML modal (<div id="billing-modal">) inside the iframe with a local approval button, bypassing Shopify's billing system. Custom modal completely removed. Clicking a plan calls /api/billing/create and immediately breaks out of the iframe using window.shopify.open(confirmationUrl, '_top') or top-level window redirection directly into Shopify's native charge approval modal / Managed Pricing screen.
Shopify Native Modal Integration Bypassed Shopify's native billing confirmation screen. Plan charges trigger Shopify's official GraphQL appSubscriptionCreate mutation returning a Shopify-hosted confirmationUrl, ensuring merchants approve charges on Shopify's official billing screen.
Free Tier ($0/mo) Required no charge approval, but had no clean reset. Instantly switches to Free Tier ($0/mo) via /api/billing/create without requesting unnecessary charges.
Decline Charge Flow In-app modal had a custom cancel button that stayed in-app. Shopify's native billing modal provides the official "Decline" button. Declining returns the merchant cleanly to the app without charging.
Reinstall Lifecycle Did not reset subscription status on app removal. The app/uninstalled webhook resets store billing status to Free Tier ($0/mo) and clears stored tokens, requiring fresh approval on reinstall.
